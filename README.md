# Brawl Champion

**Опис гри:**
Brawl Champion — це незалежний проєкт, створений для розваг і демонстрації програмістських навичок. Гра поєднує прості механіки ігрового процесу та інтерактивний інтерфейс.

## Увага

Ця гра жодним чином не пов'язана з компанією **Supercell** або її продуктами. Усі використані ресурси створені самостійно або взяті з відкритих джерел відповідно до ліцензії. Назва, механіки та дизайн гри є незалежною розробкою автора.

**Гра не є приватним сервером** і не передбачає використання будь-яких несанкціонованих модифікацій офіційних продуктів. Це виключно фанатський проєкт, створений для розваг і не є порушенням правил чи прав власності.

Гра також **не є програмою для чітів**, не містить донату, реклами або платного контенту. Усі функції гри доступні безкоштовно для всіх користувачів.

**Supercell** є зареєстрованою торговою маркою, і цей проєкт не використовує її інтелектуальну власність або несе будь-яке пряме чи непряме посилання на їхні ігри.
